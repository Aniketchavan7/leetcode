### 💻 Optimal Implementations

#### Java Solution
```java
class Solution {
    public int maxCount(int m, int n, int[][] ops) {
        for (int[] op : ops) {
            m = Math.min(m, op[0]);
            n = Math.min(n, op[1]);
        }
        return m * n;
    }
}
```

#### Python 3 Solution
```python
class Solution:
    def maxCount(self, m: int, n: int, ops: list[list[int]]) -> int:
        for a, b in ops:
            m = min(m, a)
            n = min(n, b)
        return m * n
```
