# Algorithmic Complexity Reference

## Master Pattern Complexity Matrix
| Pattern | Primary Data Structure | Average Time | Worst Time | Space |
| :--- | :--- | :--- | :--- | :--- |
| Two Pointers | Array / String | O(n) | O(n) | O(1) |
| Sliding Window | Deque / Hash Map | O(n) | O(n) | O(k) |
| Monotonic Stack | Stack | O(n) | O(n) | O(n) |
| Binary Search | Sorted Array | O(log n) | O(log n) | O(1) |
| Dynamic Programming | Matrix / Array | O(n * k) | O(n * k) | O(n) |
| Graph BFS / DFS | Adjacency List | O(V + E) | O(V + E) | O(V) |
| Trie | Prefix Tree | O(L) | O(L) | O(N * L) |
