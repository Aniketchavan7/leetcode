# FAANG Coding Interview Evaluation Rubric (Google SWE L4/L5)

## 1. Four Assessment Dimensions
1. **Analytical Ability**: Clarifying ambiguous requirements, identifying constraint boundaries, formulating optimal algorithmic approaches before writing code.
2. **Coding Speed & Cleanliness**: Idiomatic syntax, meaningful variable naming, clean modularization, DRY principles.
3. **Complexity Analysis**: Immediate derivation of tight Big-O time and auxiliary space bounds.
4. **Verification & Edge Testing**: Proactive walk-through of empty inputs, single-element cases, integer overflow limits, and off-by-one indices without interviewer prompting.
