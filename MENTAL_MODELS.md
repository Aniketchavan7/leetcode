# Top 10 Algorithmic Mental Models

1. **State Machine / DFA**: Model complex string validation as finite states
2. **Monotonic Invariant**: Maintain strictly increasing/decreasing order for O(1) queries
3. **Complement Lookup**: Hash map reverse indexing for pair matching
4. **Divide & Conquer**: Decompose into independent subproblems with base cases
5. **Topological Ordering**: Indegree 0 queue processing for dependency resolution
