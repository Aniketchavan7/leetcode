### 💻 Optimal Implementations

#### Java Solution
```java
class Solution {
    public int countSegments(String s) {
        int ans = 0;
        for (String t : s.split(" ")) {
            if (!"".equals(t)) {
                ++ans;
            }
        }
        return ans;
    }
}
```

#### Python 3 Solution
```python
class Solution:
    def countSegments(self, s: str) -> int:
        return len(s.split())
```
