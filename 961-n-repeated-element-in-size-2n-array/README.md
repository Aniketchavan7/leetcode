### 💻 Optimal Implementations

#### Java Solution
```java
class Solution {
    public int repeatedNTimes(int[] nums) {
        Set<Integer> s = new HashSet<>(nums.length / 2 + 1);
        for (int i = 0;; ++i) {
            if (!s.add(nums[i])) {
                return nums[i];
            }
        }
    }
}
```

#### Python 3 Solution
```python
class Solution:
    def repeatedNTimes(self, nums: list[int]) -> int:
        s = set()
        for x in nums:
            if x in s:
                return x
            s.add(x)
```
